# Security

CASCADE currently accepts security reports privately through the repository owner's preferred contact channel. Do not include private datasets, credentials, patient information, or unpublished models in a public issue.

CASCADE configuration and geometry files are treated as untrusted input only to the extent covered by normal JSON, CSV, NPZ, VTK, and `svv` loaders. Run third-party inputs in an isolated environment. The software is research software and is not a medical device.
